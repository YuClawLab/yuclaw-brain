# Contributing to YUCLAW

Contributions are licensed under Apache-2.0: by submitting a contribution
you agree it is provided under the Apache License 2.0 (the repository
license), with no additional terms.

## Developer Certificate of Origin

Every commit must carry a DCO sign-off certifying you have the right to
submit the work under the project license
([developercertificate.org](https://developercertificate.org)):

```
Signed-off-by: Your Name <your.email@example.com>
```

Add it with `git commit -s`.

## Ground rules

- Research surfaces follow the repository's language rules: research
  classifications, never recommendations; adverse results print as
  measured; statistics are registered in the protocol chain before they
  are computed.
- The public evidence record (ledger roots, protocol registry) is
  append-only — pull requests that edit history will be declined.

*Research and education only — not investment advice.*
