A1.0 METHODOLOGICAL STATUS
Rules introduced by A1 are PROSPECTIVE BINDINGS of previously
under-determined parent-spec choices. They are not represented as
uniquely implied by the parent specification. They were selected
without access to governed outcome values and become governing only
upon registration of A1. READ_SCOPE = STRUCTURAL_ONLY.

A1.1 EVIDENCE STORE BINDING
- Store: yuclaw_events.public.events; accepted row := event_status =
  'accepted'.
- Event identity: event_id MUST be non-null and unique within the
  eligible row set; violation → verdict NOT_EXECUTABLE.
- Issuer key := events.ticker (string equality as stored).
- Event date := session-of(events.available_as_of) per A1.2.
- Accession := parsed from persisted events.source_url by the locked
  regex r'/Archives/edgar/data/(\d+)/(\d{18})/' → accession =
  d[0:10]-d[10:12]-d[12:18]. No match → accession NONE (counted as
  UNPARSED; no filing edge). No join to events_raw (no locked FK).
- Filing identity := accession string. Rule 1 (extracted-from) exists
  iff both events' accessions are equal and non-NONE.

A1.2 TRADING CALENDAR AND SESSION MAPPING
- Calendar := persisted module v3/u350/market_calendar.py at the source
  commit recorded in the run entry (file sha256 recorded), adopted BY
  REGISTRATION: NYSE full-day closures + weekend rule, session close
  16:00:00 America/New_York.
- session-of(ts) := the EARLIEST trading session S such that close(S)
  >= ts converted to America/New_York. Hence: ts at or before a
  session's 16:00:00 ET close → that session (boundary inclusive);
  ts after the close → the next trading session; weekend/closure
  timestamps → the next trading session.
- Rule 3 "within 5 trading days strictly after" := 1 <=
  session_index(later) - session_index(earlier) <= 5.

A1.4 CUTOFF, WINDOW, NULLS, EMPTIES
- Availability field := events.available_as_of; timezone :=
  America/New_York via A1.2; granularity := trading session.
- Read window := sessions [2026-07-03 .. last completed session
  strictly before the registration session of this addendum],
  inclusive at both ends. DISCLOSURE: 2026-07-03 is an NYSE closure in
  the registered calendar, so the first in-window session is

- Empties: zero eligible events → INSUFFICIENT; zero story-clusters

A1.5 GRAPH NODE SET, CLUSTERING, IDENTIFIERS
- Vertices for clustering := EVENTS ONLY. Filings, components,
  issuer-days, registry runs, forward outcomes, surfaces, truncation
  sites are NOT vertices; edges touching them (rules 11–16) are typed
  ANNOTATIONS and never contribute to connectivity.
- Story := maximal connected component of events under rules 1 and 3.
  Story-cluster := maximal connected component of events under the
  union of EXECUTABLE event↔event edges among rules 1–10 (A1.6).
- Issuer-event projection printed per parent text; issuers are
  isolated vertices in it (parent literal reading, DISCLOSED).
- c := the number of connected components of the graph represented by
  the specific structure record on which r is computed. For a maximal
  story-cluster record c = 1 by construction; c remains an explicit
  field in the canonical calculation.
- Cluster id := first 16 hex of sha256 of the sorted newline-joined
  member event_ids. Member order := event_id ascending. Edge order :=
  (rule number, event_id_a, event_id_b) ascending, a < b by event_id.

A1.6 EDGE RULES 5–16: ARTIFACTS, EXECUTABILITY, COVERAGE
- Rule 5 shared-source: normalized URL := parse with a strict RFC-3986
  split (scheme, host, port, path, query, fragment); require scheme
  and host present (else UNPARSED); lowercase scheme and host; drop
  the port only if it equals the scheme default (80 http / 443 https),
  otherwise retain byte-for-byte; path retained byte-for-byte except
  one trailing '/' removed; query retained byte-for-byte; fragment
  dropped; relative or otherwise malformed URLs → UNPARSED; null/empty
  → NONE. No other library heuristic may alter the string. Edge iff
  normalized URLs byte-equal AND parsed accessions differ (both
  non-NONE).
- Rule 6 shared-exhibit: no persisted exhibit-id field → ABSENT.
- Rule 7 cascade: artifact := events.parent_event_id; edge iff
  child.parent_event_id == parent.event_id (both eligible).
- Rules 8, 9 SUPPORTS/CONTRADICTS: no persisted relation store → ABSENT.
- Rule 10 amendment: no persisted intake linkage, no "/A" forms → ABSENT.
- Rule 11 affects-component (annotation): artifact := the LAST persisted
  public.signal_snapshots row of the event's session for the event's
  ticker whose evidence_event_ids contains the event_id, where
  LAST := maximal signal_time, ties broken by maximal snapshot_id
  (string order); null signal_time rows are never selected; no such
  row → NONE. Annotation := the set of component keys in
  component_anatomy whose persisted evidence_ids list contains the
  event_id (the persisted attribution record "lists that component").
  DISCLOSURE: no per-component weight is persisted (component objects
  carry confidence, evidence_ids, not_implemented, rationale, score);
  the parent's "nonzero weight" is bound prospectively to listing by
  evidence_ids membership.
- Rule 12 changes-label (annotation): signal_label of LAST snapshot of
  session D vs LAST snapshot of session D-1 (same LAST definition) for
  the ticker → changed / unchanged / NONE (either side missing).
- Rule 13 tested-by: registry data_window is free text → ABSENT.
- Rule 14 matured-into (annotation): artifact := public.track_record;
  completed row := (ticker, session D) with ANY of return_1d,
  return_5d, return_20d non-null (the parent's "any k"); annotation
  := the list of completed k in {1, 5, 20}; none non-null or no row
  → NONE.
- Rules 15, 16: no per-event exclusion/drop records → ABSENT.
- EDGE-COVERAGE STATE (canonical, mandatory):
  ABSENT means the registered relation type has no persisted store
  available to this read. It does NOT mean zero matching relations
  existed, that the relation is empirically absent, or that it could
  not change connectivity. Three states are distinct and printed:
  EXECUTED (n edges, n may be 0) | ABSENT | NOT_EXECUTABLE.
  Canonical field: edge_rule_coverage {executable: [1,2,3,4,5,7 +
  annotations 11,12,14], absent: [6,8,9,10,13,15,16],
  structural_completeness: PARTIAL}.
