CAR panel — clustered inference + sample anatomy

Peer model vs SPY — what these CARs measure: each event's expected return is α+β·(equal-weight mean return of the other covered names in this lens), estimated over the 60 trading days before the event (gap 6, minimum 30 usable days). The peer model absorbs sector-common moves — a commodity swing that lifts every name in the lens cancels out — so the residual isolates issuer-specific reaction. A SPY-relative CAR answers a different question (movement vs the broad market) and widens whenever the sector as a whole moves; the Lab's cohort event study reports that variant. All values below are peer-model CARs in percent, direction-aligned.
