# YUCLAW — One-Pager

Open-source AI signal-research stack. **Research and education only — not financial advice.**

**Contact**: [github.com/YuClawLab](https://github.com/YuClawLab) | [@Vincenzhang2026](https://twitter.com/Vincenzhang2026)

---

## What it is

A free, MIT-licensed quant-research toolkit that runs end-to-end on a single
NVIDIA DGX Spark GB10. Signals are generated by a 6-component composite
aggregator over a 39-ticker universe, scored by a local LLM, and selectively
hash-anchored on Ethereum Sepolia testnet for a tamper-evident audit log.

A daily digest goes out to the public Telegram channel at 09:35 ET on
weekdays; the live dashboard refreshes every 30 minutes.

## What you can do with it

```bash
pip install yuclaw
yuclaw today          # Daily market regime + top buy signals
yuclaw signals        # Raw top-15 with scores and prices
yuclaw paper          # Alpaca paper-trading bridge (7 safety nets)
yuclaw verify LUNR    # Look up a ticker's on-chain anchor
```

## Components

| Module | What it does |
|---|---|
| Signal aggregator v2.4 | 6-component composite over 39 tickers (leveraged ETFs blocklisted) |
| Macro regime detector | CRISIS / RISK_OFF / RISK_ON from SPY/TLT/GLD/UUP momentum |
| Local LLM scoring | News sentiment + daily synthesis via Llama 3.1 70B on Ollama |
| Risk engine | VaR / CVaR / Kelly via historical simulation |
| Forward track record | Daily entries built by cron after market close |
| Hash anchoring | Selected signal hashes anchored on Ethereum Sepolia testnet |
| Alpaca paper bridge | `yuclaw paper` — paper-URL-guarded, drawdown kill switch, audit log |

## Tech stack

- **Model**: Llama 3.1 70B (Q4_K_M, ~42 GB) via Ollama on NVIDIA DGX Spark GB10. The Ollama tag `nemotron-3-super-local` carries a financial-analyst system prompt. Real Nemotron 3 Super 120B is wired in `yuclaw/core/router.py` as a dormant OpenRouter fallback path.
- **Hardware**: NVIDIA DGX Spark GB10 (Grace Blackwell, 128 GB unified memory, ARM64) — zero cloud LLM dependency. Finnhub is the cloud data source for prices and news.
- **Audit**: SHA-256 hash anchors on Ethereum Sepolia testnet. Not Groth16 zk-SNARK proofs of strategy correctness — the Circom compliance circuit in [yuclaw-trust](https://github.com/YuClawLab/yuclaw-trust) is a design spec for that future system.
- **Data**: Finnhub (prices, news, earnings), EIA (oil inventories), yfinance (oil futures).

## What it is NOT

- Not a trading robot. Signals only; you decide.
- Not financial advice. Past performance does not predict future returns.
- Not a zk-SNARK proof system today — hash anchors only.
- Not connected to live broker accounts — paper trading only.
- Not for paid pilots, premium subscriptions, or enterprise capital — it's a single-machine open-source research stack.
