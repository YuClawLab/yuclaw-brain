🚀 **YUCLAW v4.0 is live — the Agent Research API**

YUCLAW reads SEC filings and turns them into **research classifications** — never buy/sell calls.
Every signal links to its source filings, carries an Evidence-Quality grade, and is hash-anchored
in a public ledger you can verify yourself.

**Try it in 3 minutes:**
```
pip install yuclaw
yuclaw demo
```
A guided "Why AMD?" journey — traced to its filings, point-in-time replayed, and independently
verified, all in your terminal.

**New in v4:** REST API · MCP server · LangChain + LlamaIndex wrappers · research memos · cascade
view · shareable signal cards.
