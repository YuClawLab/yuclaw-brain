# YUCLAW v4.0.0 — The Agent Research API

> **DRAFT — for VinZhang review before the GitHub release is published.**

YUCLAW reads SEC filings and turns them into **research classifications** — never buy/sell
calls. Every signal links to its source filings, carries an Evidence-Quality grade, and is
hash-anchored in a public, git-anchored ledger so anyone can independently verify it existed
at a given time and hasn't changed since.

v4.0 makes that pipeline **agent-native and `pip install`-able**.

```bash
pip install yuclaw
yuclaw demo
```

`yuclaw demo` is a ~3-minute guided "Why AMD?" journey on a real, frozen signal — traced to its
filings, point-in-time replayed, and verified against the public ledger.

---

## What v4 is

- **Evidence-first.** A signal is a *research classification* (8-label locked vocabulary —
  `STRONG_BULLISH … BEARISH_WATCH`, deliberately **no** BUY / SELL / SHORT), backed by the exact
  SEC filings it was computed from and an Evidence-Quality grade.
- **One contract everywhere.** REST, CLI, MCP, and the Python SDK all return the same Pydantic v2
  `ResearchResponse` — signal, C1–C9 component anatomy, confidence, evidence, cascade, compliance,
  and a `ledger_hash`. No surface drifts from another.
- **Agent-native.** First-class MCP server plus LangChain and LlamaIndex wrappers — drop a YUCLAW
  signal into an agent as a tool or a retriever.
- **Verifiable.** `yuclaw verify` checks a signal's content hash against the public
  [`yuclaw-trust`](https://github.com/YuClawLab/yuclaw-trust) ledger. Verification is **integrity,
  not merit**: it proves the signal existed and is unaltered — it does not validate the claim.

| Share | Self-contained, compliance-carrying HTML signal card |
| Keys | SHA-256-hashed API keys, free/anon daily tiers, usage metering |

## Upgrading from v3.0 / v2.x

- **`pip install yuclaw` now installs the v4 research stack** (v3 evidence pipeline + v4 API/CLI +
  the `yuclaw_py` SDK). The `yuclaw` command is the research CLI; the old v2.x momentum/trading CLI
  has been retired.
- The legacy v2.x stack is preserved under [`archive/v2/`](../../tree/main/archive/v2) for history.
  It is **not** packaged or served.
- Optional extras: `pip install "yuclaw[api]"` (REST server), `"yuclaw[mcp]"` (MCP), `"yuclaw[agents]"`
  (LangChain/LlamaIndex).
